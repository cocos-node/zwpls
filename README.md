# zwpls 
version:0.0.1
快捷终端命令,存储常用命令,方便快捷

# 安装
```bash 
curl -sSL https://raw.githubusercontent.com/cocos-node/zwpls/main/install.sh| bash 
```

# 使用方法
```bash
  zwpls                     # 交互式使用
  zwpls add "名称" "命令"     # 添加命令
  zwpls your_key            # 执行命令
  zwpls help                # 查看帮助
```
